# 레트로 포켓PC 스타일 비쥬얼드(Bejeweled) 구현 계획서 (모바일 완벽 대응)

사용자가 제공한 고전 윈도우 모바일(Pocket PC / Windows CE) 비쥬얼드 스크린샷의 비주얼과 조작감을 **모바일 스마트폰/태블릿 및 데스크톱 브라우저 전 기기에서 완벽하게 플레이 가능하도록** 설계된 Match-3 보석 퍼즐 게임 구현 계획입니다.

---

## 1. 모바일 환경 최적화 설계 (Mobile Ergonomics & Responsiveness)

- **터치 제스처 & 조작감**:
  - **직관적인 스와이프(Swipe) & 드래그(Drag)**: 보석을 터치한 상태에서 상하좌우로 살짝 밀면 즉시 인접 보석과 교환.
  - **원터치 탭(Tap) 선택 & 이동**: 보석 탭 시 선택 링 활성화 → 인접 보석 탭 시 즉시 스와프 (스타일러스 펜 또는 한 손 엄지 조작 지원).
  - **터치 제스처 충돌 방지**: 게임 보드 영역에 `touch-action: none` 적용하여 화면 스크롤, 풀투리프레시(Pull-to-refresh), 더블탭 확대 방지.
  - **모바일 햅틱 진동(Haptic Vibration API)**:
    - 보석 스와프 시 부드러운 10ms 틱 진동.
    - 매치 성립 시 20ms 경쾌한 진동.
    - 특수 보석(폭발 보석, 번개 큐브) 발동 시 역동적인 다중 진동 패턴 (`[30, 20, 50]ms`).
- **반응형 뷰포트 및 레이아웃**:
  - **`100dvh` (Dynamic Viewport Height) 대응**: 모바일 브라우저(Safari, Chrome)의 상/하단 주소창 및 제스처 바가 나타나거나 사라져도 보드가 잘리지 않도록 정밀 계산.
  - **Safe Area Inset 반영**: 노치(Notch) 및 다이내믹 아일랜드 영역을 고려한 `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` 여백 처리.
  - **2가지 디스플레이 모드**:
    1. **모바일 전체화면 몰입 모드 (Full Mobile)**: 기기 화면 너비에 꽉 차게 8x8 보석 그리드와 UI를 배치하여 이동 중 편안하게 플레이.
    2. **PDA 기기 래퍼 모드 (Retro Handheld PDA)**: 실제 iPAQ 핸드헬드 기기 외형(케이스, 버튼, 스타일러스) 속에 게임 화면이 들어있는 레트로 감성 뷰.
- **모바일 오디오 자동 재생 정책(Auto-play Policy) 해결**:
  - iOS Safari 및 Android Chrome의 오디오 차단 정책을 준수하여, 화면 첫 터치(`touchstart` / `pointerdown`) 시 `AudioContext.resume()`을 백그라운드에서 자동 활성화.

## 2. 비주얼 테마 (Pocket PC 2002/2003 Vintage)

- **정통 PDA 윈도우 프레임**:
  - 상단 윈도우 모바일 시스템 바: 윈도우 깃발 로고, 프로그램 이름(`Bejeweled`), 통신 화살표 아이콘, 스피커 볼륨, 실시간 디지털 시계(로컬 기기 시간 연동), 닫기(X) 버튼.
  - 상단 스코어 헤더: 특유의 짙은 네이비 메탈릭 헤더, 필기체 `score` 로고와 노란색 굵은 숫자 점수판, 오른쪽 클래식 `HINT` 버튼.
  - 하단 진행 게이지 튜브: 3D 금속 프레임 캡슐과 양옆의 빨간색/초록색 구슬 노드, 클리어 진행도에 따라 차오르는 크리스탈 액체 게이지.
  - 최하단 커맨드 바: `Game Tools` 팝업 메뉴 트리거, 음악/효과음 토글(`♪x`), 일시정지(`||`), 새 게임(`✖`), 온스크린 키보드(`⌨`) 아이콘.

- **원작 보석 디자인 (7종 정밀 Facet SVG 렌더링)**:
  1. **Red Ruby**: 빨간 사각 볼록 큐브 (입체적인 4분할 격자 하이라이트)
  2. **White Diamond**: 흰색 8각 브릴리언트 컷 (투명하고 빛나는 다이아몬드 면)
  3. **Orange Citrine**: 주황색 가로 육각 보석 (황금빛 단면)
  4. **Yellow Topaz**: 노란색 마름모 / 정방형 다이아몬드 (중앙 피라미드 컷)
  5. **Green Emerald**: 녹색 8각 에메랄드 컷 (짙은 녹색과 밝은 에메랄드 반사광)
  6. **Blue Sapphire**: 파란색 눈물형 / 다이아몬드 드롭형 보석 (깊은 코발트 블루)
  7. **Purple Amethyst**: 보라색 정삼각형 보석 (영롱한 자수정 광택)

## 3. 핵심 게임 엔진 (Match-3 Core Engine)

- **8x8 보드 데이터 구조 및 상태 머신**:
  - `Grid[8][8]` 보석 상태 관리 (ID, 타입, 위치, 특수 상태, 애니메이션 좌표 오프셋).
  - 상태 머신: `IDLE` (입력 대기) → `SWAPPING` (교환 애니메이션) → `CHECKING` (매치 판정) → `RESOLVING` (보석 폭발 및 특수 효과) → `FALLING` (중력 낙하) → `REFILLING` (상단 새 보석 생성) → `CHAIN_CHECK` (연쇄 콤보 판정) → `GAME_OVER / LEVEL_CLEAR`.
- **스와프 및 조작**:
  - 매치가 성립하지 않을 경우 쫀득한 스와프 복귀(Bounce-back) 애니메이션 및 튕김 사운드/진동.
- **특수 보석 및 매치 규칙**:
  - **3매치**: 기본 보석 파괴 및 점수 획득.
  - **4매치 (Flame Gem / 폭발 보석)**: 불꽃이 일렁이는 특수 보석 생성. 매칭 시 주변 3x3 범위를 화려하게 폭파.
  - **5매치 (Hypercube / 번개 보석)**: 무지개빛으로 빛나는 하이퍼큐브 생성. 다른 보석과 스와프 시 보드 위의 해당 색상 보석 전체 파괴.
  - **L/T자 매치**: 십자형 번개 이펙트 발생.
- **연쇄 콤보 (Chain Multipliers)**:
  - 1단 매치 이후 낙하로 발생하는 추가 매치마다 2x, 3x, 4x 점수 배율 및 사운드 피치 상승.
- **힌트(Hint) & 셔플(Shuffle) 엔진**:
  - 보드 내 유효한 이동이 있는지 백그라운드 탐색.
  - `HINT` 클릭 시 이동 가능한 보석에 반짝이는 스파클 파티클 및 펄스 이펙트 표시.
  - 더 이상 이동할 수 없는 경우("No More Moves") 포켓PC 경고 대화상자 출력 후 자동 보드 재배치(Shuffle).

## 4. 게임 모드 구성

1. **클래식 모드 (Classic Mode)**:
   - 원작과 동일하게 매치를 할 때마다 하단 게이지가 차오름.
   - 게이지가 100%에 도달하면 레벨 업! 보너스 점수 획득 및 다음 레벨로 진행.
   - 유효한 수가 없고 셔플도 불가능할 때 게임 종료.
2. **타임어택 모드 (Time Attack Mode)**:
   - 하단 게이지가 시간 경과에 따라 실시간으로 줄어듦.
   - 빠른 연속 매치와 콤보를 통해서만 게이지를 채워 버틸 수 있는 긴장감 넘치는 스피드 모드.
   - 게이지가 0이 되면 게임 오버.
3. **무제한 연습 모드 (Endless / Zen Mode)**:
   - 타이머나 게임 오버 압박 없이 끝없이 플레이할 수 있는 릴랙스 모드.
   - 누적 최고 점수 기록, 콤보 연습, 보석 효과 감상 가능.

## 5. 사운드 및 햅틱 피드백 시스템 (Web Audio & Vibration)

외부 오디오 파일 로딩 지연 없는 100% 브라우저 자체 신디사이저:
- **선택 클릭음**: 따뜻한 픽셀 터치 틱(Tick) 사운드 + 8ms 미세 햅틱.
- **스와프 효과음**: 경쾌한 미끄러짐 음향.
- **보석 매치음**: 영롱한 크리스탈 하프 차임 (C-E-G-C 화음) + 20ms 햅틱.
- **콤보음**: 연쇄마다 옥타브와 피치가 상승하는 팡파르 차임.
- **특수 보석 폭발음**: 묵직한 베이스 럼블과 화이트 노이즈 버스트 + 강한 햅틱.
- **무효 스와프**: 부드러운 목재 튕김(Clack) 음.
- **레벨업**: 포켓PC 특유의 클래식 신스 멜로디 승리 축하음.
- 볼륨 조절 및 즉시 음소거/복구 토글.

## 6. UI/UX 및 모바일 반응형 구성

- **Game Tools 메뉴**:
  - `New Game` (새 게임 시작)
  - `Select Mode` (클래식 / 타임어택 / 무제한)
  - `Display Mode` (모바일 전체화면 / 레트로 PDA 케이스 뷰 전환)
  - `High Scores` (로컬 스토리지 연동 최고 점수 및 통계)
  - `Haptics & Sound` (진동 / 사운드 On / Off)
- **점수 팝업 & 비주얼 이펙트**:
  - 보석이 깨진 위치에서 떠오르는 부유 점수 텍스트 (`+100`, `+500 Combo x2`).
  - 보석 깨질 때의 8방향 유리 파편 파티클 애니메이션.
  - 상단 시계 실시간 반영(현재 로컬 시간 연동).
